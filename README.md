# Viaggio in Israele con Isacco

Italian website for Isacco Charig, a licensed tour guide in Israel.

Built with plain HTML, CSS, and JavaScript. No build step or dependencies.

## Local preview

From the repository folder, run:

```sh
python3 -m http.server --bind 127.0.0.1 8000
```

Open http://127.0.0.1:8000/ in your browser. Refresh after editing files.

## Files

- `index.html` — page content
- `css/home.css` — styles
- `js/home.js` — interactions and animations
- `images/` — photos and icons
